Foundation

Rafiq Hub

A small server you run yourself. It packages Rafiq Core with a local model server so everyone at home, or in a class, shares one private companion.

What it does

  • One command to start, using Docker Compose.
  • A local model server included, on CPU or on a graphics card.
  • An optional larger database for many users.
  • Reachable only from the machine it runs on until you choose to open it to your network.

Your data

Your Hub, your data. No account with us is needed, and no secrets ship in the configuration.

Status

A first version exists: the server, a choice of two model servers and an optional database. Multi-user schools and encrypted sync follow in Phase 2.
