Products / Rafiq Chat

Phase 1

Rafiq Chat

A chatbot for your terminal first, then desktop and web. It talks to a model on your own computer by default and keeps your conversations and memory as files you can read.

See how it works

Pick a step.

What it does

  • Chat from the command line, in one shot or interactively, with answers streamed as they arrive.
  • A badge on every answer: which model ran, on which provider, and whether that was this device, your own network or a cloud service.
  • Memory you control: one document you can read, edit and delete from, used at the start of each conversation.
  • Consent in place: when a cloud model needs permission, you see exactly what would be sent and approve or decline on the spot.
  • History and export as plain Markdown and JSON.

Your data

Conversations and memory stay on your device. Nothing reaches a cloud model unless you grant that specific flow, and every grant is listed in one place and can be withdrawn.

Status

The command-line client exists and is tested against Rafiq Core. Desktop and web follow in Phase 1. The repository opens publicly at the first installable milestone.
