Foundation

Rafiq Core

One service on your device that every Rafiq product talks to. It routes requests to models, stores your data encrypted, and decides what is allowed to leave.

What it does

  • A model gateway that treats local and cloud models alike and labels every answer with the model and where it ran.
  • A permission engine: every outbound connection needs a named grant, and anything that never leaves the device needs none.
  • A tamper-evident audit log of every decision, which you can read and verify.
  • An encrypted database per user, with keyword and semantic search.
  • Memory as a versioned document you own, plus a one-command export of everything.
  • A standard API, so existing tools that speak the common chat format work unchanged.

Your data

Core is where the promises are enforced. A request to a provider you have not granted is refused before anything is sent, and the refusal itself is logged.

Status

Built and tested: gateway, permissions, consent flow, audit log, encrypted storage, memory, scheduling and the local API.
