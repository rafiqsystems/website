Phase 4

Rafiq OS

A refreshed GNOME desktop whose front door is a single command palette. Type what you want in your own words, and Rafiq does it with the machine's own capabilities, inside limits you can see.

What it does

  • One shortcut raises the palette: launch, find, arrange windows, change settings, or ask in plain language.
  • Agents run multi-step work in a sandbox that contains only the files and network destinations you granted.
  • The operating system's own functions, such as files, windows, clipboard, settings and notifications, are offered to agents as MCP servers under the same consent rules as any connector.
  • A live panel shows what Rafiq can see right now, with revoke on every row.
  • The classic desktop stays one toggle away.

Your data

A tool that lies about what it needs gains nothing: it runs with a filesystem that contains only the granted paths and a network that reaches only the granted hosts. Every decision is logged.

Status

Phase 4. The Linux sandbox and the agent runtime are built and tested. The palette and the desktop image are designed, not yet built.
