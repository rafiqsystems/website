Manzar

MAN-zar·nouna view

Plays the videos you already have, from one folder you choose. The same queue continues on the car display.

See how it works

Pick a step.

What it does

  • A library built from a single folder you pick with the system picker.
  • Phone screen, lock-screen controls and the car display all drive one player, so switching between them never restarts playback.
  • Single files also arrive through "open with".

Your data

The app does not request the internet permission, so it cannot send anything anywhere. It asks for no storage permission either: it sees only the folder you chose.

Where it stands

In development for Android and Android Auto.
