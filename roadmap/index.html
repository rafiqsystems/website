Roadmap

Each phase ends with something installable. Dates are targets, not promises, and will be revised in public.

  1. Phase 0: Foundation (November to December 2026)Principles, threat model, licensing and architecture decisions published. Repository, signed release pipeline and this site. Arabic and English evaluation set from real lecture material. A working rafiq chat command against a local model.
  2. Phase 1: Core and Rafiq AI (January to March 2027)Core 0.1: model gateway for local and cloud providers, memory, hybrid search, agent runtime, permission engine with audit log, Vault. Rafiq AI 0.1 on desktop and web. Hub 0.1 as a one-command self-hosted server.
  3. Phase 2: Rafiq Study and Connect (April to June 2027)The study companion runs on Core with pluggable transcription, OCR, search and models. Any school can self-host it. First connectors: files, calendar, mail, feeds, browser.
  4. Phase 3: Rafiq PA and Mobile (July to September 2027)Daily briefing, inbox and calendar triage, reminders, prayer times, proactive help behind grants. Android, then iOS, with on-device models and encrypted sync.
  5. Phase 4: Rafiq OS (October to December 2027)Agent runtime and capability sandbox on Linux, macOS and Windows. A shell overlay so any app can hand work to Rafiq. Prototype of an immutable Linux image.
  6. Phase 5: Hardening and 1.0 (first half of 2028)External security audit with findings fixed in public. Reproducible builds verified by a third party. 1.0 of Core, AI, Study, PA and Mobile. Maintainers beyond the founder.

Now: Phase 0. The repository opens publicly at the first installable milestone.
