# rafiqsystems.com

Public website for Rafiq. Static HTML and CSS, no JavaScript, no third-party requests, no cookies,
no analytics. Deployed to GitHub Pages on every push to `main`.

Edit the HTML directly. Shared styles live in `assets/site.css`. Preview locally with
`python3 -m http.server 8080` from this directory.
